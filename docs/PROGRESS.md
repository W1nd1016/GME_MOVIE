## 每个任务怎样推进

1. 从上表选取一个任务号。读取对应路线条目和上一项验收记录，查清本项输入、依赖和遗留问题。
2. 在 `docs/plans/` 写本项计划，列出文件范围、设计、风险和可验证的完成条件，提交用户审批。
3. 获批后从 `main` 建任务分支，先写测试再实现。在本机运行测试、冒烟检查和计划内的实验。
4. 用验收结果更新本表，包括实际分支、完成日期、结果和遗留问题。有真实指标时登记实验，有影响后续任务的决定时登记决策。将实现、测试和记录一起提交到任务分支。需要合并时按 [开发规则](../AGENTS.md) 征得用户同意，使后续分支能取得前置任务的代码。

阶段 0 验收后，按路线图迁移到 MicroLens 并重跑基线，再依次推进语义 ID、流式 warm-up 和可选的 LLM 增强。进入各阶段时，根据前一阶段产物细化下一项任务计划。
